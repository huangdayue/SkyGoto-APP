# 对齐星空图功能设计方案 V2（含旋转视角交互）

## 一、功能概述

交互式星空图，用户可通过触摸拖拽自由旋转/平移/缩放视角，查看天空任意的部分。

核心交互定义：

| 手势 | 功能 | 说明 |
|------|------|------|
| **单指拖拽** | **旋转视角** | 移动视场中心，相当于抬头环顾天空 |
| **双指缩放** | **拉近/拉远** | 从全天空（180°视场）到局部（30°视场） |
| **点按星点** | 选中校准星 | 触控选择对齐目标 |
| **双击** | 重置全景 | 回到默认全天空视图 |

## 二、投影方式

V1 用的鱼眼投影只能看全天空，不适合局部旋转。V2 改用 **立体赤平投影（Stereographic Projection）**，天然支持视场中心可变。

### 2.1 Stereographic 投影公式

```
给定：
  FOV = 当前视场角（度），默认 100°（近似全天空）
  centerAlt, centerAz = 当前视场中心的 Alt/Az
  starAlt, starAz = 星点的 Alt/Az

步骤 1. 将地平坐标转为三维单位向量
  sx = cos(starAlt) × sin(starAz)
  sy = cos(starAlt) × cos(starAz)
  sz = sin(starAlt)

步骤 2. 将视场中心旋转到屏幕 Z 轴方向
  （先用 centerAz 旋转 YZ，再用 centerAlt 旋转 XZ）

步骤 3. Stereographic 投影到屏幕
  scale = canvas_radius × 2 / tan(FOV/2 × π/180)
  x_screen = scale × vx / (1 + vz) + cx
  y_screen = -scale × vy / (1 + vz) + cy

  其中 (vx, vy, vz) 是旋转后的向量

步骤 4. 可见性裁剪
  if (vz < -0.2) 不绘制  // 超过视场边缘的星忽略
```

相比鱼眼投影，Stereographic 的好处：
- 视场中心可任意移动（旋转视角的数学基础）
- 角度变形较小，星星的相对位置看起来更自然
- 放大到局部时依然保持可读性

### 2.2 视场中心管理

```kotlin
data class ChartViewState(
    val centerAlt: Float = 60f,     // 视场中心高度角（默认60°=天顶略偏南）
    val centerAz: Float = 180f,     // 视场中心方位角（默认180°=正南）
    val fov: Float = 100f           // 视场角（度），100°≈全天空
)
```

拖拽时：

```
// 拖拽像素 → 角度增量
val sensitivity = 0.3f  // 像素转角度系数
val dAz = -dx × sensitivity × (fov / canvasWidth)
val dAlt = dy × sensitivity × (fov / canvasWidth)

centerAz = (centerAz + dAz) % 360
centerAlt = (centerAlt + dAlt).coerceIn(0f, 85f)
```

缩小时：

```
// 双指缩放 → FOV 变化
val scaleFactor = 1.0f / zoom
fov = (fov × scaleFactor).coerceIn(30f, 160f)
```

### 3.2 快捷按钮

在星空图底部放置几个**快速视角按钮**，方便用户一键跳转：

```
[全天空] [天顶] [选中星居中] [南天] [北天]
```

- **全天空**：centerAlt=60, centerAz=180, FOV=100（默认全景）
- **选中星居中**：自动计算视场中心对准选中星
- **天顶**：centerAlt=90（天顶俯视图）
- **南/北天**：centerAz=180/0

## 四、交互流程图

### 4.1 完整的对齐+星图交互流程

```
用户打开对齐页 → 星图加载（计算可见星位置）
                       ↓
            备选星列表 + 星图同步显示
                       ↓
          触摸选择 → 星图上高亮该星，列表同步
                       ↓
        点击「GOTO」→ 赤道仪转到该星
                       ↓
        用户拖拽星图放大→ 查看星附近细节
                       ↓
        通过方向键手动居中星点
                       ↓
        点击「同步」→ :CM# 完成校准
```

### 4.2 星图与星列表的双向同步

```
星图上点击星点 → 列表选中对应行 → 详情区更新
列表点击行名 → 星图该星高亮 → 可选"居中到该星"
```

## 六、估算

- **代码量**：~350 行（StarChartView 250 + ViewModel + ControlViewModel 修改 + UI 集成）
- **开发周期**：约 1-2 天
- **依赖**：零新增
- **性能**：Canvas 重绘时只重新计算可见星的屏幕坐标（不是每帧全量计算）
- **双重刷新策略**：
  - 拖拽/缩放时：每帧实时重绘（~16ms 刷新），仅调投影公式，**不重新计算坐标转换**
  - 星位置更新：30 秒一次全局刷新（调用 applyPrecession + getAltitudeAzimuth）
