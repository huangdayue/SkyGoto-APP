# LX200 协议详解

## 概述

LX200 是 Meade 公司为其天文望远镜开发的串行通信协议，OnStep/OnStepX 完全兼容此协议。命令以 `:` 开头，以 `#` 结尾，所有响应也以 `#` 结束。

**通信参数：**
- 波特率：9600, 19200, 38400, 115200（OnStep 默认 9600）
- 数据位：8
- 停止位：1
- 无奇偶校验

---

## 命令格式

### 通用格式
```
:Command# → 响应
```

### 带参数命令
```
:CommandParam# → 响应
```

### 坐标命令格式
- **赤经 (RA)**：HH:MM:SS 或 HH.MMMM
- **赤纬 (Dec)**：sDD*MM:SS 或 sDD.MMMM（s 为符号 +/-）

## 4. GOTO 命令

### 4.1 直接坐标 GOTO
```
:SetRA#        → 设置目标赤经
:SetDec#       → 设置目标赤纬
:Goto#          → 执行 GOTO
```

**实际命令格式（OnStep 扩展）：**
```
:Sr HH:MM:SS.T#  → 设置目标赤经
:Sd sDD*MM:SS#   → 设置目标赤纬
:Goto#           → 执行 GOTO
```

**示例：**
```
:Sr 05:34:32#    → 设置 RA = 5h 34m 32s
:Sd +45*12:34#   → 设置 Dec = +45° 12' 34"
:Goto#            → 执行 goto
```

### 4.2 已知天体 GOTO
| 命令 | 描述 | 示例 |
|------|------|------|
| `:MA object#` | 移动到已知天体 | `:MA M31#` |
| `:M5 object#` | 快速移动（跳过校验）| `:M5 M42#` |

**支持的天体格式：**
- 梅西耶天体：`M1`, `M31`, `M110`
- NGC天体：`NGC224`, `NGC7000`
- 星云/星系名称（部分支持）

### 4.3 GOTO 状态查询
| 命令 | 描述 | 响应 |
|------|------|------|
| `:GZ#` | 获取目标方位 | `123:45#` |
| `:GH#` | 获取目标高度 | `+45:23#` |
| `:GS#` | 获取跟踪状态 | `Tracking#` |

## 9. 响应格式

### 成功响应
- 数字：`+12:34:56#` 或 `123.45#`
- 文本：`Ready#`, `Tracking#`, `Idle#`

### 错误响应
- 通常为 `0#` 或 `FAIL#`

### GOTO 状态
| 状态 | 含义 |
|------|------|
| `#`（无响应）| 命令接受，继续执行 |
| `0#` | 目标已在限位内 |
| `1#` | 无效坐标 |
| `2#` | 超出限位 |

## 10. 实际通信示例

### 连接并查询状态
```
→ :V#           ← OnStep 4.24#
→ :GS#          ← Tracking#
→ :GR#          ← +05:34:32#
→ :GD#          ← +45:12:34#
```

### 执行 GOTO M31（仙女座星系）
```
→ :Sr 00:42:44# ← 设置 RA
→ :Sd +41:16:09# ← 设置 Dec
→ :Goto#        ← 开始 goto
（等待中）
→ :GR#          ← +00:42:45# （接近目标）
→ :GD#          ← +41:16:10#
```

### 手动控制
```
→ :R9#          ← 设置 256x 速率
→ :Me#          ← 向东移动
（等待一段时间）
→ :Q#           ← 停止
```

## 11. 安卓端实现要点

### 11.1 连接方式
```kotlin
// 蓝牙串口
BluetoothSocket.connect()
// WiFi TCP
Socket(IP, Port)
```

### 11.2 命令发送
```kotlin
suspend fun sendCommand(command: String): String {
    val fullCommand = "$command#"
    outputStream.write(fullCommand.toByteArray())
    return readResponse()
}
```

### 11.3 坐标系转换
- **RA**: String "HH:MM:SS.T" ↔ Double (小时)
- **Dec**: String "sDD*MM:SS" ↔ Double (度)

### 11.4 心跳机制
每 5 秒发送 `:GS#` 或 `:GR#` 保持连接
