## 1. 天体库命令 (Library Commands)

OnStepX 提供了一套完整的 `:L` 系列命令用于管理用户天体库。

### 1.1 查询命令

| 命令 | 功能 | 响应 |
|------|------|------|
| `:LI#` | 获取当前对象信息 | `名称,类型` |
| `:LR#` | 获取对象信息+坐标，并跳到下一条 | `名称,类型,RA,Dec` |
| `:L?#` | 获取剩余记录数 | `n#` |

### 1.2 浏览命令

| 命令 | 功能 |
|------|------|
| `:LN#` | 跳到下一个对象 |
| `:LB#` | 跳到上一个对象 |
| `:LC[n]#` | 跳到第 n 个对象 |
| `:L$#` | 跳到库名称记录 |

### 1.3 操作命令

| 命令 | 功能 |
|------|------|
| `:Lo[n]#` | 选择目录 (0-14) |
| `:LD#` | 清除当前记录 |
| `:LL#` | 清除当前目录 |
| `:L!#` | 清除所有目录 |
| `:LW 名称,类型#` | 写入新对象 |

## 3. 存储格式

```cpp
typedef struct {
    char    name[11];      // 对象名称 (11字符)
    uint8_t code;          // 高4位=目录号(0-14), 低4位=类型(0-15)
    uint16_t RA;           // 赤经 (0-65536 -> 0-360°)
    uint16_t Dec;          // 赤纬 (0-65536 -> -90° to +90°)
} libRec_t;
```

**编码方式：**
- RA: `RA / 65536.0 * 360.0` 度
- Dec: `Dec / 65536.0 * 180.0 - 90.0` 度

## 4. 关键发现

### 4.1 OnStepX 内置库是空的！

**重要：** OnStepX 的 `:L` 命令是用于**用户自定义**天体库，系统**不包含**预装的梅西耶或其他天体目录。

### 4.2 APP 需要内置数据库

因此，我们的 APP **必须内置**梅西耶天体数据库，而不是依赖 OnStepX 的库系统。

### 4.3 使用 GOTO 命令

对于预定义天体（如 M31），APP 需要：
1. 从本地数据库获取 M31 的 RA/Dec 坐标
2. 使用 `:Sr RA#` 和 `:Sd Dec#` 设置目标
3. 使用 `:MS#` 执行 GOTO

## 5. 梅西耶目录实现方案

### 5.1 数据库结构

```kotlin
data class MessierObject(
    val id: String,        // "M31"
    val name: String,       // "仙女座星系"
    val type: String,       // "GAL" (星系)
    val ra: Double,         // 0.7122 (小时)
    val dec: Double,        // 41.2692 (度)
    val constellation: String, // "Andromeda"
    val magnitude: Double, // 3.4
    val description: String
)
```

### 5.2 查询方式

```kotlin
// 本地查询
val m31 = catalog.query("M31")
if (m31 != null) {
    // 发送 GOTO 命令
    sendCommand(":Sr ${formatRA(m31.ra)}#")
    sendCommand(":Sd ${formatDec(m31.dec)}#")
    sendCommand(":MS#")
}
```

## 6. 命令流程示例

### GOTO M31 (仙女座星系)

```
APP 本地数据库:
M31, RA=00h 42m 44s, Dec=+41° 16' 09"

发送序列:
1. :Sr 00:42:44#  → 设置目标赤经
2. :Sd +41*16:09# → 设置目标赤纬  
3. :MS#           → 执行 GOTO
```

### 遍历内置目录

```
:LN#   → 下一条记录 (APP本地)
:LB#   → 上一条记录 (APP本地)
:LI#   → 显示当前对象 (OnStepX用户库)
```

## 7. 目录编号

OnStepX 支持 15 个目录 (0-14)，其中 0-6 为用户目录。

| 目录号 | 用途 | 建议用途 |
|--------|------|---------|
| 0 | 用户目录1 | 梅西耶天体 |
| 1 | 用户目录2 | NGC 天体 |
| 2 | 用户目录3 | 自定义目标 |
| 3-14 | 保留 | - |

---

## 8. 数据同步注意事项

1. **OnStepX 库容量有限** - 约 200-500 条记录（取决于 NV 大小）
2. **不依赖设备存储** - APP 应独立存储完整数据库
3. **写入后可验证** - APP 可将常用目标写入 OnStepX 作为备份
