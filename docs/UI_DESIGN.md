## 5. 方向控制面板 (D-Pad)

```
        ┌─────────────────────┐
        │         ▲           │
        │         N           │
        │    ◄    │    ►      │
        │    W    │    E      │
        │    ◄    │    ►      │
        │         ▼           │
        │         S           │
        └─────────────────────┘

布局说明:
- 中心为圆形方向按钮区
- 四个方向: 上(N) 下(S) 左(W) 右(E)
- 每方向两侧显示 ▲ ▼ ◄ ► 图标
- 按住持续移动，松开停止
```

## 10. 颜色方案

| 名称 | 色值 | 用途 |
|------|------|------|
| Primary | #0A1628 | 主背景 |
| Secondary | #1E2A3A | 卡片背景 |
| Accent | #00D4FF | 强调色/按钮 |
| Accent2 | #00FF88 | 成功/追踪中 |
| Warning | #FFB800 | 警告 |
| Error | #FF4444 | 错误 |
| TextPrimary | #FFFFFF | 主要文字 |
| TextSecondary | #B0B8C4 | 次要文字 |

## 11. 字号规范

| 元素 | 字号 |
|------|------|
| 页面标题 | 24sp |
| 卡片标题 | 18sp |
| 正文 | 16sp |
| 坐标显示 | 20sp (等宽) |
| 按钮文字 | 16sp |
| 说明文字 | 14sp |

---

## 12. 交互反馈

| 动作 | 反馈 |
|------|------|
| 按钮点击 | 缩放 0.95 + 颜色变亮 |
| 方向按住 | 按钮高亮 + 坐标实时更新 |
| GOTO 执行 | 进度圆环 + 目标坐标显示 |
| 连接成功 | Toast 提示 + 震动 |
| 断开连接 | 红色状态 + 自动重连提示 |

---

## 13. 动效设计

| 场景 | 动效 |
|------|------|
| 页面切换 | 淡入淡出 300ms |
| 按钮反馈 | 缩放 150ms |
| 追踪状态 | 呼吸灯效果 2s 循环 |
| GOTO 进行中 | 旋转扫描动画 |
| 列表加载 | 骨架屏 placeholder |
