# UI 设计文档

> **文档版本：** 2.0（更新于 2026-05-21）

## 概述

SkyGoto APP 采用 Jetpack Compose + Material3 构建，适配夜间天文观测使用深色主题。4 个底部导航 Tab：连接 / 控制 / 目录 / 设置。

---

## 1. 页面结构

```
MainActivity
└── Scaffold（底部导航）
    └── NavHost（导航图）
        ├── ConnectScreen（连接页面）
        │   ├── BluetoothTab（已配对设备列表）
        │   └── WiFiTab（IP + 端口）
        │
        ├── ControlScreen（控制页面）
        │   ├── StatusBar（RA/Dec + Alt/Az + 追踪状态）
        │   ├── DirectionPad（N/S/E/W + STOP）
        │   ├── MoveRateSelector（5 档速率）
        │   ├── TrackingToggle（追踪开关）
        │   ├── GotoPanel（目标坐标 + 取消 GOTO）
        │   └── GotoProgressDialog（GOTO 进度弹窗）
        │
        ├── CatalogScreen（目录页面）
        │   ├── CategoryTabs（全/梅西耶/NGC/太阳系/恒星）
        │   ├── SearchBar
        │   ├── ObjectList（可点击发起 GOTO）
        │   └── ObjectDetailSheet（详情 + GOTO 按钮）
        │
        └── SettingsScreen（设置页面）
            ├── LimitsSettings（限位角度）
            ├── TrackingSettings（追踪模式）
            ├── GotoSettings（GOTO 速率、到位容差）
            ├── LocationSettings（经纬度）
            └── DeviceInfo（固件版本、关于）
```

## 2. 颜色方案（暗色主题）

| 名称 | 色值 | 用途 |
|------|------|------|
| Primary | `#0A1628` | 主背景 |
| Secondary | `#1E2A3A` | 卡片背景 |
| Surface | `#152238` | 表面 |
| Primary Container | `#1E3A5F` | 主要容器 |
| On Primary | `#00D4FF` | 主要文字/按钮（青色）|
| Secondary Container | `#2A3F5F` | 次要容器 |
| Tertiary | `#00FF88` | 成功/追踪中（绿色）|
| Error | `#FF4444` | 错误/停止 |
| On Surface | `#FFFFFF` | 主要文字 |
| On Surface Variant | `#B0B8C4` | 次要文字 |

**强调色：** `#00D4FF`（青色，用于按钮、链接、焦点）  
**成功色：** `#00FF88`（绿色，用于追踪中、到位成功）  
**警告色：** `#FFB800`（用于超限、异常状态）  
**错误色：** `#FF4444`（用于断开、紧急停止）

## 4. 控制页面（ControlScreen）

### 4.1 状态栏

```
┌──────────────────────────────────────────────┐
│  RA  12:34:56    Alt  +45°23'                │
│  Dec +45:12:34   Az   123°45'   [追踪中 ●]   │
└──────────────────────────────────────────────┘
```

- RA/Dec 显示当前赤道仪坐标
- Alt/Az 显示当前地平坐标
- 右侧追踪状态指示（绿色圆点 + "追踪中" 或 灰色 "已停止"）

### 4.2 方向控制面板

```
        [N]
    [W]   [STOP]   [E]
        [S]
```

- 四个方向按钮（N/S/E/W）
- 中间 STOP 按钮（红色，紧急停止）
- 按住持续移动，松开停止

### 4.3 速率选择

```
[导星 1x] [居中 8x] [寻找 20x] [快速 48x]
```

- 横向排列，4 个可选按钮
- 当前选中项高亮显示

### 4.4 追踪开关

```
[追踪开关]  ←  大按钮，一键开启/关闭
```

### 4.5 GOTO 面板

```
┌──────────────────────────────────────────────┐
│ 目标: M31  仙女座星系                          │
│ RA: 00h 42m 44s   Dec: +41°16'09"            │
│                        [取消 GOTO]            │
└──────────────────────────────────────────────┘
```

- 显示当前 GOTO 目标（如果有）
- 点击取消 GOTO（`:Q#` 发送两次）

### 4.6 GOTO 进度弹窗（GotoProgressDialog）

```
┌──────────────────────────────────────────────┐
│         ★ 正在 goto ★                         │
│                                              │
│   目标: M31  仙女座星系                       │
│   RA: 00h 42m 44s   Dec: +41°16'09"          │
│                                              │
│   当前: 12h 34m 56s   +45°12'34"             │
│                                              │
│   ████████████░░░░░░░░░░░░  35%              │
│                                              │
│              [取消 GOTO]                     │
└──────────────────────────────────────────────┘
```

- **模态拦截**：`DialogProperties(dismissOnBackPress=false, dismissOnClickOutside=false)`
- 每秒更新当前坐标
- 到位后自动消失并显示成功 Banner

### 4.7 GOTO 结果 Banner（GotoResultBanner）

```
┌──────────────────────────────────────────────┐
│  ✓ GOTO 完成 - M31 仙女座星系                  │
└──────────────────────────────────────────────┘
```

- 底部弹出，3 秒自动消失
- 支持手动滑动关闭

## 8. 交互反馈

| 动作 | 反馈 |
|------|------|
| 按钮点击 | 缩放 0.95 + 颜色变亮 |
| 方向按住 | 按钮高亮 + 坐标实时更新 |
| GOTO 执行 | 进度弹窗 + 目标坐标显示 |
| 连接成功 | Toast 提示 |
| 断开连接 | 红色状态提示 + Banner |
| 到位完成 | 绿色成功 Banner（3 秒自动消失）|

---

## 9. 动效

| 场景 | 动效 |
|------|------|
| 页面切换 | 淡入淡出 300ms |
| 按钮反馈 | 缩放 150ms |
| 追踪状态 | 绿色圆点呼吸灯 2s 循环 |
| GOTO 进度 | 进度条动画更新 |
| Banner 弹出 | 从底部滑入 300ms |
| Banner 消失 | 3 秒后自动滑出 |
